# SkyStore — Интернет-магазин на Django

Учебный веб-проект интернет-магазина, разработанный в рамках курса по Python. В текущей версии реализовано знакомство с архитектурой Django, настроена маршрутизация для ключевых страниц и интегрированы базовые HTML-шаблоны с использованием Bootstrap.

## Реализованный функционал
* Создано и зарегистрировано Django-приложение `catalog`.
* Настроена маршрутизация с подключением URL-файлов приложения через `include`.
* Реализована главная страница (`/` или `/home/`) с витриной товаров.
* Реализована страница контактов (`/contacts/`) с отображением реквизитов компании.
* **Дополнительное задание:** реализована форма обратной связи на странице контактов с обработкой `POST`-запросов и выводом данных в консоль сервера.

## Инструкция по локальному запуску

Для того чтобы развернуть и запустить проект локально, выполните следующие шаги в терминале:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd DjangoHW1
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   # Создание venv
   python -m venv venv

   # Активация для Windows:
   venv\Scripts\activate

   # Активация для macOS/Linux:
   source venv/bin/activate
   ```

3. **Установите необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите локальный сервер разработки Django:**
   ```bash
   python manage.py runserver
   ```

После запуска проект будет доступен в браузере по адресу: [http://127.0.0](http://127.0.0)
